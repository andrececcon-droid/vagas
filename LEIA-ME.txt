COMO SUBIR (computador): 
1) Apague no GitHub os arquivos vagas.yml e headhunters.yml da RAIZ e o vagas.yml antigo de .github/workflows.
2) Add file > Upload files: arraste o CONTEUDO da pasta vagas (incluindo a pasta .github e docs). 
   Se o navegador nao enviar a pasta .github (pasta oculta), crie os 2 arquivos em
   Add file > Create new file com o nome .github/workflows/vagas.yml e .github/workflows/headhunters.yml
   e cole o conteudo das copias em workflows-copia/.
3) Actions > Buscar vagas > Run workflow. Depois Buscar contatos de head hunters.
